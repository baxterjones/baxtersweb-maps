# Changelog

## 1.1.11

* Updated the plugin name and readme.

## 1.1.10

* Fixed per-POI background colours, including shorthand values and colours entered without a leading hash.
* POI groups retain a shared custom colour when all grouped POIs use the same colour.

## 1.1.9

* Existing saved road routes remain available when the API key is removed.
* Maps without saved road geometry are calculated when a valid API key is connected.
* Added routing lifecycle guidance and resolved a translation-comment warning.

## 1.1.7

* Fixed global POI background colours in the preview and frontend.
* Clearing an API key restored fallback lines at that stage of development.
* Improved live preview updates and popup positioning.

## 1.1.6

* Added a bounded 2 km retry for rural route points outside the default road-snapping distance.

## 1.1.4

* Fixed missing cached road geometry display.
* Moved route display and route colour to the Styles tab.
* Renamed the map appearance tab to Styles.
* Added persistent openrouteservice connection status and a combined Save & Test API action.
* Improved preview behaviour, translations, external-service disclosure, and documentation links.

## 1.0.6

* Moved settings under Tools and bundled Leaflet locally.
* Added route marker text colour, alphabetical markers, duplicate marker handling and clearer loop examples.
* Expanded external-service disclosure and Plugin Check compatibility.

## 1.0.5

* Added map height, border radius and marker label settings.

## 1.0.4

* Added the dedicated admin screen and improved generated fields and defaults.

## 1.0.3

* Prevented duplicate field setup.

## 1.0.2

* Improved onboarding and added the uninstall data preference.

## 1.0.1

* Added automated ACF field setup.

## 1.0.0

* Initial release.
